# 圣诞节里程碑：Enlumor 0.2.0 预览版

日期：2026-11-22。范围：11-23（周一）到 12-25（周五），共 5 周，对应[长期规划](2026-11-06-agent-system-plan.md)的第 3 到 7 周。

> **状态：方向已定。** 作者 2026-11-22 决定：先发版，发版后做视频、开始宣传。
> 第七节里还有几项没定，没定之前按建议的默认做法施工。
> 这份文档只管到圣诞节和之后两周的宣传期。它和长期规划不一致的地方列在第八节。

## 一、目标

**12 月 25 日前，发布第一个带 Surfing 的公开版本 0.2.0，然后用一条演示视频开始对外宣传。**

做到下面四件事才算完成：

1. **装得上。** 一个没见过 Enlumor 的同学，从 GitHub 下载，10 分钟内对自己的论文问出第一个带原文引用的回答。
2. **说得清。** 我们手里有一张绑定提交号的成绩表：同一份代码、每题跑 3 次。别人问"它靠谱吗"，能拿数字回答。
3. **有人用过。** 至少 2 位作者之外的读者用它读过一篇论文，卡在哪里有记录。
4. **有人看到。** 发版之后发出一条 60 到 90 秒的演示视频，带着下载链接。

圣诞节前不加任何新的大功能。要做的是把已经写好的东西修到能交给别人，交出去，再让人知道。

Enlumor 的仓库没有 Release，没有 tag，没有 topics，简介里没有提 AI。过去 14 天仓库页面只被访问过 1 次。

从这张表能看出四件事：

1. **有人用的项目都在持续发安装包。** NeoRead 建仓第 3 天就发了第一个版本，7 周发了 36 个。不发版的 uxie 和 ScholarPhi，几年下来都很小。Enlumor 最有特点的 Surfing 从没进过任何公开的安装包，README 自己也写着"不代表 GitHub 已上传公共下载"。现在最缺的不是功能，是别人装得上。
2. **不要拼功能的广度。** 同类项目大多在比翻译、总结、文献库和 Zotero 集成。PaperQuay 一个人铺开了文献库、翻译、知识图谱和综述写作，8 月 11 日之后没有再发版。VISION 已经写明这些不做，这个判断是对的。
3. **我们的差异点，别人也开始做了。** Open Paper 的卖点就是"每个回答都能点回原文"，还公开了自己的评测集。NeoRead 的回答也带引用。"引用可点"已经是标配。Enlumor 还独有的是三件事：引用必须逐字存在于原文，由代码校验；一步一步带读者看过去；发送全文前先确认。首页的演示要突出这三点，并把成绩表公开出来。
4. **让人几分钟内看到效果。** NeoRead 在空书库里放了"先体验示例文档"，首次使用有指南带着配置模型。Enlumor 手里已经有自己写的 Lumen 示例论文，可以直接用。

## 六、视频和宣传

### 视频

60 到 90 秒。横屏一版放 README 和视频站，竖屏一版放竖屏平台。六个镜头：

| 时间 | 画面 | 字幕要说的事 |
| --- | --- | --- |
| 0 到 8 秒 | 一篇陌生的论文，满页术语 | 论文难读，不知道从哪开始 |
| 8 到 20 秒 | 打开 PDF，提一个真实的问题；弹出"发送全文前确认"，点确认 | 发什么给模型，由你决定 |
| 20 到 45 秒 | 回答出现，页面一步一步滑到原文对应的位置 | 不是给你一段总结，是带你看原文 |
| 45 到 60 秒 | 点一条引用，回到原文并高亮 | 每条引用都逐字存在于原文，由代码校验 |
| 60 到 75 秒 | 成绩表：28 题、每题 3 次、绑定版本 | 靠不靠谱，有数字，也有限制 |
| 75 到 90 秒 | 开源、本地优先、自带密钥；下载地址 | 去哪里下载 |

录制的规矩：

- 全部用真实录屏，不用生成的界面。README 一直是这么做的。
- 论文用 CC BY 许可的，或者自己写的 Lumen。
- 画面里不能出现 API Key。录之前检查设置页和终端。
- 不说"替你读完"，说"带你读懂"。这是 VISION 的定位。
- 成绩数字出现时，同一屏带上限制：只测过 DeepSeek，28 题。
- 用到同学的画面或原话，先征得同意。

### 宣传

- **首发**（12-24）：视频加一篇帖子，带下载链接，写明这是预览版、欢迎提 issue。
- **后续**（12-26 到 01-08）：每周一条。现成的题材有两个：两位同学试用时卡在哪里、我们怎么改的；成绩表是怎么跑出来的。后一条就是长期规划第八节说的《我怎样给 PDF 阅读 agent 做评测》。
- **渠道**（建议的默认，等你定）：中文先做 B 站和小红书，读者是读论文吃力的本科生和研究生。英文的 Show HN 和 Reddit 放到 1 月，等英文 README 和英文字幕准备好。
- **不做**：不买量，不刷 star；不说"最强"，不说"替代某某"；同类项目只在被问到时如实比较。

宣传带来的问题要有人接。宣传期每天留 30 分钟回复，回不过来就先停发新内容。
