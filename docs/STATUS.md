## 现在能用的

- **阅读与批注**：搜索、跳页、缩放、旋转、标签页、缩略图；高亮、下划线、删除线、便签、箭头、画笔。导出另存一份 PDF，不改原文件。
- **编辑库是默认链路**：每次修改都有记录，撤销和重做在重启后仍然有效。旧工作区从 v4 升到 v5 前先做完整性检查和备份；`--legacy-editing` 可以退回旧链路。见 [EDITING.md](EDITING.md)。
- **Surfing（问答）**：针对整篇论文提问。发送全文前要用户确认。模型可以看页面图、重读页面、搜索；答案是校验过的 JSON，格式坏了自动纠错一次；引用必须是论文里真实存在的段落。涉及多处时，会一步一步带读者看过去。思考档用模型自己提供的档位。
- **评测**：带二维码的测试 PDF，App 打开时扫码进入测试模式；另有命令行验收脚本，每次生成带截图的报告（会调用真实模型，要花钱）。

## 已知问题（不用先做设计决定就能修）

详细的出处和行号见[系统 review](reviews/2026-11-06-system-review.md)的"现在就能修的具体 bug"。

1. 等回答时滚动、点击、翻页、选字、切窗口会取消请求。
2. OpenAI 推理模型必然失败（发了 `max_tokens` 和 `temperature`）。
3. 星火走 Surfing 必然失败。
4. 同一个标识不能连续撤销。
5. 导出把所有标识写成用户的；移动过的便签导出后回到原位。
6. 带路结束后，空格和方向键仍被占用。
7. 三处"发送范围"的说明互相矛盾。
8. `npm run dev` 不构建 token worker。
9. 1000 笔画的页面上，擦除后界面最长卡 79 到 120 毫秒（预算 50 毫秒），因为每次都整页重建。
10. 没有 CI、没有格式化和 lint；运行过程（模型每一步说了什么）不落盘。
